# 🌊 Epitech C Pool - Day 08

### 📂 Structure du Projet
* **include/** 📑 : Contient `my.h` avec tous les prototypes.
* **lib/my/** 📚 : Sources de la bibliothèque statique.
* **tests/** 🧪 : Dossier dédié aux Unit Tests.

---

### 🛠️ Fichiers de la Task 04 & 05
* **my_strdup.c** 📝 : Alloue de la mémoire et y copie une chaîne de caractères existante.
* **my_show_word_array.c** 📺 : Affiche le contenu d'un tableau de chaînes (`char **`), un mot par ligne.
* **my_str_to_word_array.c** ✂️ : Découpe une phrase en mots selon les caractères alphanumériques et les stocke dans un tableau.
* **convert_base.c** 🔢 : Convertit un nombre d'une base source vers une base de destination en utilisant un `int` comme pivot.

---

### ⚙️ Gestion du Makefile
Le **Makefile** à la racine automatise la compilation :

* **make** 🔨 : Compile la `libmy.a` et les programmes du jour.
* **make clean** 🧹 : Supprime les fichiers objets (`.o`).
* **make fclean** 🗑️ : Supprime les objets et les binaires finaux.
* **make re** 🔄 : Nettoie tout et relance la compilation.
